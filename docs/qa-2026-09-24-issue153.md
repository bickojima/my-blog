## CMS entry load regression check

Initial comprehensive results said 150/150 passed, but image review found the T07/T50 editor forms were blank. Those results are preserved in `initial-review.json` as invalid for verifying editor data. Instrumented browser logs showed the evidence fixture returned an invalid nested Git Trees response and emitted `Unrecognized front-matter format`; after changing it to repository-relative tree paths and returning children relative to the requested folder, a focused real-click check displayed the mock article title and body. T07/T50 require both actual field values; the final three-device run passed all 150 scenarios with these stronger assertions.

The matching E-29 CMS Playwright regression check now requires the existing title and body to load before performing an actual title edit. A focused PC run on Node.js 22.23.3 passed; the post-rebase Playwright suite passed 457 with 8 expected skips (465 total), and comprehensive evidence passed 150/150 across PC/iPad/iPhone.
