制定日：2026年9月9日

playwright-home のGmail連携には、次の方針を適用します。

- **取得・利用**：対象メールの識別子、送信元、件名、本文、受信日時を読み、本人が利用するサービスの認証コード取得と対象メールの既読化に使います。
- **送信・共有**：認証コードだけを対象サービスの認証画面へ送信します。メール本文の外部共有、データの販売・広告利用・AI学習への利用は行いません。
- **保存・削除**：メール本文・認証コードを通常ログや結果レポートに保存しません。認証情報はアクセスを制限して保管し、利用終了時にバックアップを含め削除します。元メールは本人がGmailで削除できます。
- **利用停止**：[Googleアカウントの接続管理](https://myaccount.google.com/connections)からアクセスを取り消せます。

Google APIから受け取る情報の使用・転送は、Limited Use要件を含む[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)に従います。

連絡先：Googleの同意画面に表示されるサポートメール。変更時は本ページを更新します。
